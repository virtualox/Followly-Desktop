# Followly Desktop

**Official releases for Followly Desktop**

Native desktop application for analyzing Instagram followers and following data. Import CSV files, compare snapshots, and export detailed reports.

---

## 📦 Downloads

Download the latest version from the [Releases](https://github.com/JustFoxLabs/Followly-Desktop/releases) page.

### Windows
- **MSI Installer** (Recommended) - Full installer with graphical wizard
- **Portable ZIP** - Single-file executable, no installation required
- Both formats are **self-contained** - no .NET runtime installation needed!

### macOS
- **DMG Installer** - Universal binary (Apple Silicon + Intel)
- Notarized by Apple for secure installation
- Requires macOS 14 Sonoma or later

### Linux (Coming Soon)
- Support for major distributions (Ubuntu, Fedora, Arch)
- AppImage and .deb packages

## 🚀 Installation

### Windows

**MSI Installer (Recommended):**
1. Download `Followly-X.X.X-Setup.msi` from [Releases](https://github.com/JustFoxLabs/Followly-Desktop/releases/latest)
2. Run the installer
3. Follow the installation wizard
4. Launch from Start Menu or Desktop shortcut

**Portable Version:**
1. Download `Followly-X.X.X-Portable-x64.zip` from [Releases](https://github.com/JustFoxLabs/Followly-Desktop/releases/latest)
2. Extract to any folder
3. Run `Followly.exe`

### macOS

**DMG Installer:**
1. Download `Followly-X.X.X-macOS.dmg` from [Releases](https://github.com/JustFoxLabs/Followly-Desktop/releases/latest)
2. Open the DMG file
3. Drag Followly to Applications folder
4. Launch from Applications or Spotlight
